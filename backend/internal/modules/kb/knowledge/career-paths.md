## Career path: Software Development Engineer (SDE)
A software development engineer designs, writes, tests and maintains the programs that products run on. Day to day this means reading existing code, building features, fixing bugs and reviewing teammates' work. Core skills are a main language such as Java, Python or C++, data structures and algorithms, SQL, Git and writing tests. How to start: pick one language and solve problems regularly, build two or three projects with a database and publish them on GitHub, and learn to explain your design choices. Interviews usually test coding problems, basics of object-oriented design and your projects. Growth runs from junior engineer to senior engineer, then either technical lead or architect.

## Career path: Full Stack Developer
A full stack developer builds both the part users see (web pages) and the part that stores and processes data (server and database). Core skills are HTML, CSS, JavaScript, a front end library such as React, a back end such as Node.js or Java Spring, SQL or a document database, and REST APIs. How to start: build a complete app such as an expense tracker with sign-up, login and a database, then deploy it so others can use it. Employers like to see a live link and clean code on GitHub. Interviews cover JavaScript fundamentals, how the web works, API design and a walkthrough of your project.

## Career path: Backend Developer
A backend developer builds the services behind apps: APIs, business rules, databases and background jobs. Core skills are a server language (Java, Python, Go or Node.js), SQL and database design, REST APIs, authentication, caching and basic cloud knowledge. How to start: build an API with a database, add login, write automated tests and document the endpoints. Learn what happens when many users call it at once. Interviews focus on data structures, database questions such as indexes and joins, API design and how you would make a service reliable. Growth leads to senior backend engineer, system designer or platform engineer.

## Career path: Data Analyst
A data analyst turns raw data into answers: cleaning it, finding patterns, building charts and explaining what the numbers mean to people who decide things. Core skills are SQL, Excel, a visualisation tool such as Power BI or Tableau, basic statistics and Python with pandas. How to start: take a public dataset, ask five clear questions, answer them with charts and write a one-page summary. Employers value clear explanation as much as technical skill. Interviews include SQL queries, statistics basics, an Excel or case exercise and questions about how you would present findings. Growth leads to senior analyst, analytics manager or data scientist.

## Career path: Machine Learning Engineer
A machine learning engineer builds systems that learn from data, such as recommendations, classifiers and forecasts, and gets them working reliably in real products. Core skills are Python, statistics and linear algebra, scikit-learn, a deep learning library, data cleaning and understanding how to measure a model honestly. How to start: finish a structured machine learning course, then build two projects end to end, from data cleaning to a simple web demo, and explain where each model fails. The field is competitive and many roles expect strong mathematics and a relevant project or research. Interviews cover machine learning basics, coding and a project discussion.

## Career path: Cloud and DevOps Engineer
A cloud or DevOps engineer helps teams build, test, release and run software reliably. The work covers servers on cloud platforms, automated build and deploy pipelines, containers, monitoring and fixing outages. Core skills are Linux, networking basics, Git, Docker, a cloud platform such as AWS or Azure, a CI/CD tool and a scripting language. How to start: deploy a small web app with Docker, set up automatic tests and deployment on every code push, and add basic monitoring. A cloud fundamentals certificate helps a beginner's resume. Interviews ask about Linux, networking, containers and how you would debug a failing service.

## Career path: Embedded Systems Engineer
An embedded engineer writes software that runs inside devices such as sensors, vehicles, appliances and medical equipment. Core skills are C and C++, microcontroller basics, reading datasheets, communication protocols such as I2C, SPI and UART, and debugging with real hardware. How to start: build small projects with a microcontroller board, such as a sensor logger or a relay controller, and document them with circuit diagrams and code. This path suits electronics, electrical and computer students who enjoy hardware. Interviews cover C, digital electronics, interrupts and your projects. Growth leads to firmware lead, systems engineer or product specialist.

## Career path: Design Engineer
A design engineer in a core engineering firm turns requirements into drawings, models and calculations for parts and machines. Core skills are a CAD tool such as SolidWorks or AutoCAD, engineering drawing standards, material and strength basics, and sometimes simulation. How to start: model a small mechanism, check it with a hand calculation and keep the files and drawings in a portfolio. Core companies often value fundamentals, so keep subject marks strong and learn from your lab work. Interviews test core subjects, drawing reading and software skills. Growth leads to senior design engineer, project engineer or manager.

## Career path: Testing and QA Engineer
A QA engineer finds problems before users do. Manual testers write and run test cases and report defects clearly; automation testers write programs that run those tests repeatedly. Core skills are testing concepts, test case design, bug reporting, SQL, basic programming and an automation tool such as Selenium. How to start: write a test plan and bug reports for a real app, then automate a few tests and run them in a pipeline. Attention to detail and clear writing matter a great deal. Interviews include testing scenarios, SQL and logic questions. Growth leads to automation engineer, test lead or quality manager, and many people move into development.

## Career path: Database Administrator
A database administrator keeps data safe, fast and available. The work covers designing tables, managing access, taking backups, tuning slow queries and planning for recovery. Core skills are SQL, database design and normalisation, indexing, backup and restore, one major database system and basic Linux. How to start: design a normalised database for a college, load sample data, then practise tuning slow queries with indexes and planning a backup. Cloud-managed databases are changing the work, so learn the basics of a cloud database too. Interviews cover joins, transactions, indexes and recovery scenarios.

## Career path: Technical Support Engineer
A technical support engineer helps customers or staff solve problems with software, hardware or networks. It is often a common first step into a technology company. Core skills are clear communication, troubleshooting, basic networking and operating systems, ticket handling and patience. How to start: write a troubleshooting guide for ten common problems and practise explaining technical fixes in plain words. Roles can lead to systems administration, cloud operations, QA or customer success. Interviews include scenario questions on how you would diagnose a problem and how you speak to a worried customer.

## Career path: Business Analyst
A business analyst connects the people who need a system with the team who builds it. The work is gathering requirements, writing them clearly, mapping processes, checking that the result matches the need and testing with users. Core skills are communication, requirement writing and user stories, process mapping, SQL basics, Excel and stakeholder management. How to start: interview users of a campus service, write a requirements document and draw the process as it is now and as it could be. Interviews are case based: how you would gather needs, prioritise and explain a trade-off. Growth leads to senior analyst, product owner or consultant.
